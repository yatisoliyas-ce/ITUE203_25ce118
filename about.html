About StudentHub

Purpose

StudentHub is a semester-long practical project that models a real student portal: requirement analysis, wireframing, and a working set of accessible HTML5 pages, without any backend or database.

Project scope

Practical 1 — Project Initiation

Defined the problem scope, user roles, key modules, navigation flow, and a minimum of ten pages, along with a sitemap, low-fidelity wireframe, and folder structure.

Practical 2 — Semantic HTML5 Pages

Built static HTML5 skeletons for the StudentHub portal using semantic tags such as header, nav, main, section, article, aside, and footer, with accessibility-friendly structure throughout.

User roles

Student
Registers, logs in, views the dashboard, manages a profile, browses events, and submits feedback.
Visitor
Browses public pages such as Home, About, Events, FAQ, and Contact before registering.

Built with

Plain, hand-written HTML5 only — no CSS, no JavaScript, and no backend. Each page is self-contained and works by opening the file directly in a browser.
